# l4d2_mhud_sendproxy3

A recreation of [Sikarii](https://github.com/Sikarii)'s [MovementHUD](https://github.com/Sikarii/movementhud) — uses [sendproxy](https://github.com/Crimson-DawnLight/L4D2MutiMod/tree/main/extensions/sendproxy) (SendProxy 3) and the EMS HUD to show pressed keys and ground/air speed on each player's own screen (type `!mhud` to open the settings menu).

## Credits

Recreates the key-press and speed display of [MovementHUD](https://github.com/Sikarii/movementhud) (MHUD) by [Sikarii](https://github.com/Sikarii), the movement HUD commonly seen on GOKZ/KZ servers.



## Important

- SendProxy 3 only supports SourceMod **1.12 and earlier**; **1.13 and above are not supported**.
- **Mutually exclusive with [l4d2_mhud](../l4d2_mhud)**: do not install both at the same time. If migrating from `l4d2_mhud`, remove the old `sendproxy.ext.2.l4d2.dll` / `sendproxy.ext.2.l4d2.so` from `addons/sourcemod/extensions/` first.
