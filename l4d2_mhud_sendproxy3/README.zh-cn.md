# l4d2_mhud_sendproxy3

复刻自 [Sikarii](https://github.com/Sikarii) 的 [MovementHUD](https://github.com/Sikarii/movementhud)，使用 [sendproxy](https://github.com/Crimson-DawnLight/L4D2MutiMod/tree/main/extensions/sendproxy)（SendProxy 3）与 EMS HUD 在各自玩家屏幕上显示对应按键与地速（输入 `!mhud` 打开设置菜单）。

## 借鉴说明

插件复刻了 [Sikarii](https://github.com/Sikarii) 的 [MovementHUD](https://github.com/Sikarii/movementhud)（MHUD，GOKZ/KZ 服务器的常用移动 HUD）的按键与空速显示。



## 重要

- SendProxy 3 仅支持 SourceMod **1.12 及以下**，不支持 **1.13 及以上版本**。
- 与 [l4d2_mhud](../l4d2_mhud) **二选一安装，不可混用**：若从旧版 `l4d2_mhud` 迁移，请先移除 `addons/sourcemod/extensions/` 下的 `sendproxy.ext.2.l4d2.dll` / `sendproxy.ext.2.l4d2.so`。
