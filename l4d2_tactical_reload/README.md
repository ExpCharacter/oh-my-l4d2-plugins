# l4d2_tactical_reload

If the magazine still has rounds left when you reload, you get one extra round (+1) once the reload completes.

## Credits

Mode 2 uses CS:GO-style reloading, based on v2.3 (2023-05-15) of [l4d2_weapon_csgo_reload](https://github.com/fbef0102/L4D1_2-Plugins/tree/master/l4d2_weapon_csgo_reload) by [Harry Potter](https://github.com/fbef0102).
