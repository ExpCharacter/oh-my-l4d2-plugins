# l4d2_colorcorrection_control

Lets each player independently toggle map color correction filters via `!cc` (or `sm_cc` in console) without affecting other players or black-and-white third-strike vision; preferences persist across map changes until the server restarts.

# 

## Important

- SendProxy 3 only supports SourceMod **1.12 and earlier**; **1.13 and above are not supported**.
