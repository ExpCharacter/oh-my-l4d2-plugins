# l4d2_mhud

复刻自 [Sikarii](https://github.com/Sikarii) 的 [MovementHUD](https://github.com/Sikarii/movementhud)，用 EMS HUD 在各自玩家屏幕上显示对应按键与空速。

## 借鉴说明

本插件复刻了 [Sikarii](https://github.com/Sikarii) 的 [MovementHUD](https://github.com/Sikarii/movementhud)（MHUD，GOKZ/KZ 服务器的常用移动 HUD）的按键与空速显示。
